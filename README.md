# Адвокатский кабинет Максима Береславцева

В каталоге `site/` находится статический макет. В `server/` находится тестовый HTTP-сервер с SQLite, тестами и прототипом Telegram-интерфейса. По последнему уточнению рабочим интерфейсом владельца станет веб-админка. Сценарии для неё и выбор уведомлений описаны в ТЗ.

## Просмотр и тесты

Требуется Node.js 24+. Установка пакетов не нужна.

```sh
npm test
npm start
```

Откройте http://127.0.0.1:8080 и заполните форму вымышленными данными. По умолчанию включён тестовый режим. Заявка попадёт в локальную SQLite, а уведомление с её номером появится в терминале. Проверки бот-интерфейса запускаются командой `npm test` через тестовый транспорт. Файл `data/appointments.sqlite` не коммитится.

Статический каталог можно разместить отдельно. В нём форма сохраняет тестовые записи только в этом браузере. Откройте «Демо-панель заявок» в футере или по ссылке после заполнения формы. В настройках нового репозитория GitHub выберите **Settings → Pages → Source → GitHub Actions**, отправьте исходники в ветку `main`, затем запустите **GitHub Pages demo**. Workflow загружает только `site/`. На всех страницах выставлен `noindex,nofollow`; любой человек со ссылкой сможет просмотреть публичный макет.

## Сервер и Telegram-прототип

Переменные перечислены в `.env.example`. Для проверки тестовых оповещений через настоящий Telegram передайте свежий `BOT_TOKEN` через хранилище секретов или локальный файл `.env`, добавьте числовые `OWNER_IDS` и нажмите Start в личном чате бота. Первому ID отправляются оповещения. Один экземпляр забирает входящие обновления long polling. У прототипа есть кнопки заявок, услуг, контактов, текста первого экрана и подтверждения публикации. В тестовом режиме с настоящим Telegram сообщения не содержат полей заявки.

Текущий live-режим относится к прежней схеме с Telegram как интерфейсом владельца. Для его активации предусмотрены HTTPS-адрес, согласованный поток данных, Telegram-реквизиты, актуальная версия согласия и два готовых HTML-документа в `LEGAL_DIR`. Для рабочего проекта по уточнённому брифу сначала нужна веб-админка. На реальных данных этот код пока не развёрнут.
